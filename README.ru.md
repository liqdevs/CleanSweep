# CleanSweep

CleanSweep помогает находить и удалять ненужные файлы в Windows. Программа бесплатная, без рекламы и подписки.

## Скачать

Откройте раздел [Releases](https://github.com/liqdevs/CleanSweep/releases) и скачайте файл **CleanSweep.exe**. Запустите его — установка, дополнительные папки и .NET не нужны.

Скачивайте `.exe` из раздела Releases, а не автоматически созданные GitHub архивы **Source code**. Если файла `.exe` в Releases пока нет, готовая версия ещё не опубликована.

## Что умеет приложение

- Находит временные файлы, кэши и другие возможные кандидаты на очистку.
- Показывает список для проверки перед удалением.
- Помогает посмотреть, чем занято место на диске, найти большие файлы и выбрать файлы или папки для удаления.
- Позволяет управлять приложениями, запускающимися вместе с Windows.

## Удаляйте осторожно

Оценка важности файлов — это предположение по имени и расположению. Содержимое файлов приложение не проверяет. Метка «неизвестный» или «низкая важность» не означает, что файл точно можно удалять. Перед подтверждением проверьте список.
