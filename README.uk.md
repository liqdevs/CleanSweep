# CleanSweep

CleanSweep допомагає знаходити й видаляти непотрібні файли у Windows. Програма безкоштовна, без реклами та підписки.

## Можливості

- Знаходить тимчасові файли, кеші та інші можливі кандидати на очищення.
- Показує список файлів для перевірки перед видаленням.
- Допомагає переглянути використання диска, знайти великі файли та вибрати файли або папки для видалення.
- Знаходить однакові файли за вмістом і дає змогу перевірити копії перед видаленням.
- Знаходить порожні папки та показує їх для перевірки перед видаленням.
- Дає змогу керувати програмами, які запускаються разом із Windows.

## Видаляйте обережно

Оцінка важливості файлів є припущенням на основі їхніх назв і розташування. Програма не перевіряє вміст файлів. Позначка «невідомий» або «низька важливість» не означає, що файл точно можна видаляти. Перевірте список перед підтвердженням.

## Очищення з командного рядка

Для автоматичного очищення запустіть `CleanSweep.exe --silent --drive C:\ --categories temp,browser_cache`. Вкажіть корінь диска та один або кілька ключів категорій через кому. Команда безповоротно видаляє файли без вікна перевірки — використовуйте лише попередньо перевірені категорії. Код завершення: `0` — успіх, `2` — неправильні аргументи, `3` — помилка сканування, `4` — частину елементів пропущено або не очищено, `5` — неочікувана помилка.
